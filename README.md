# Say What Actually Broke

One line (148 characters, limit 200): an error message that tells the brutal truth — the save button never saved anything — funny enough to repeat to a coworker, plain enough to ship in a real product dialog.

> Error: the save button never saved anything. It just sat there, glowing, lying to you for three years. Your work is gone. The button has been fired.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
